02

Claude Desktop

Install the extension

Three steps, no terminal needed.

  1. Download ssh-auditor.mcpb.
  2. Double-click it, or drag it onto Settings → Extensions in Claude Desktop, then choose Install.
  3. The server URL comes pre-filled with this address. Change it only if engineers reach the server by another name.

Don't add it as a custom connector. Custom connectors connect from Anthropic's cloud and can't reach the internal network. The .mcpb runs a small bridge on your own computer, inside the network, using the Node.js that ships with Claude Desktop. If your organization restricts extensions, an admin has to allow it first.

Capabilities

What Claude can do

Six tools, the same operations you have on the auditor page.

list_tests

The test catalog, with each test's category and impact.

list_profiles

Device profiles and policies available on the server.

start_scan

Starts a scan of a host with a profile, policy and tests.

get_scan

Follows a running scan and returns its results.

cancel_scan

Stops a scan that is still running.

compare_scans

Compares two scans by id, or a scan against a JSON export.

Same guardrails as the web

The server applies the target allowlist and each device profile's limits to every request, from the web or from Claude; Claude can't go past them. Tests with medium or high impact also need an explicit confirmation.
