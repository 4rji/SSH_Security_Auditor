Claude Desktop

  1. Download ssh-auditor.mcpb.
  2. Open it with a double click, or drag it onto Settings → Extensions in Claude Desktop, and choose Install.
  3. The server URL comes filled in with this address. Change it only if engineers reach the server by another name.
Don't add this server as a custom connector: those connect from Anthropic's cloud and can't reach the internal network. The .mcpb runs a small bridge on your own computer, inside the network, using the Node.js that Claude Desktop ships with. If your organization restricts extensions, an admin has to allow it first.

What Claude can do

  • list_tests, list_profiles: the tests, device profiles and policies.
  • start_scan, get_scan, cancel_scan: run a scan and follow it.
  • compare_scans: compare two scans by id, or against a JSON export.

The server applies the target allowlist and each device profile's limits to every request, from the web or from Claude; Claude can't go past them. Tests with medium or high impact also need an explicit confirmation.

Examples

  • "Audit the SSH negotiation of 10.0.0.5 with the generic profile."
  • "Compare that scan with the previous one and tell me what got worse."
  • "Compare the scan of 10.0.0.5 with this JSON export I'm giving you."
  • "List the available tests and their impact level."
